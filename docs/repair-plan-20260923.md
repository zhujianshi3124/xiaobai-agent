## 2. 高危四条：本会话回代码的独立取证结论

> 每条都给"可复放取证 + git 定性（原因先于修法）+ 建议修法"。**只呈事实，裁决权在协调侧/用户。**

### 高危① 面板体检操作台 400 —— 根因单一，且连带两屏恒不渲染（性质：客户端字段漏赋值）

- **取证（`toolkit:panel/client/index.js`，按符号定位）**：
  `beginFix` 的 `setDlg({ copy, issueId, plan, phase:"confirm" })`、`beginRollback` 的
  `setDlg({ copy, entry, plan, phase })`、`beginSnapshot` 的 `setDlg({ copy, snap, plan, phase })`
  —— **三处都没写 `kind` 字段**；而消费侧四处全按 `dlg.kind` 分派：
  `confirmDlg` 的 `execUrl = dlg.kind==="fix" ? …apply/execute : dlg.kind==="rollback" ? …rollback/execute : …snapshot-restore/execute`。
  `dlg.kind === undefined` ⇒ 三目恒落**最后一条兜底分支** ⇒ 修正/回滚的 execute 请求恒打
  `/snapshot-restore/execute` ⇒ 服务端 `panel/index.js` 那句 `if (plan.kind !== "snapshot-restore") throw PlanError("plan-kind-mismatch")`
  命中 `PLAN_ERROR_STATUS` 表 ⇒ **恒 400**。快照恢复因"恰好"是兜底目标而单独正常。
- **同一根因的第二半**：`:1475` `dlg.kind==="fix"` 才渲染"将执行"清单、`:1483` `dlg.kind==="snapshot"` 才渲染"变化预览"
  ⇒ **两屏恒不渲染**；`:1493` 完成文案同理恒取最后一支。**一处赋值修三个症状**，不需要动服务端。
- **为什么三道锁至今抓不到**：`doctor/apply|rollback|snapshot-restore` 六条路由的既有用例只覆盖**服务端**
  （`p1-smoke.mjs` 三条"registered"+ 三条 405 + CSRF 面；`p24-ui-matrix.mjs` 直调 execute 端点且**自己传 token**）。
  全仓 `grep dlg.kind|beginFix` 在 `test/`+`scripts/` **零命中** ⇒ 客户端选 URL 这一步无人钉 —— 与"仓内全绿抓不到"的 H5 先例同族。
- **建议修法（单笔 R1）**：三处 `setDlg` 补 `kind:"fix"/"rollback"/"snapshot"`；并把 `confirmDlg` 的兜底分支从
  "默默选 snapshot-restore" 改成 **fail-closed**（`kind` 未知 ⇒ 本地报错不发请求），防止同类漏赋值再次变成静默打错端点。
  先钉后修：补 4 条客户端驱动用例（三入口各一条 URL 选择 + 一条"kind 未知不发请求"），走既有"直驱 handler + response 桩"路子（避 libuv 环境性失红）。

### 高危② 引擎点名越部署名单 —— 点名只查注册表、不查部署配置（性质：实现本就不收口，非回归）

- **取证**：`toolkit:lib/web-search-local/index.js`
  `requestedEngines(searchReq)` 的合法性判据是 `typeof ENGINES[key] !== 'function'` ⇒ **只对照 `ENGINES` 注册表**；
  `runSearch` 里 `const engines = requestedEngines(searchReq) ?? engineList(cfg)` ⇒ **显式点名整体取代部署链**（注释自陈"override REPLACES the configured chain entirely"）。

  ⇒ 模型点名 `engine:'360'`/`'sogou'` 照样命中实现并真打外网。**与 debt A#25 ① 的"如实边界"一致**（配置面删除只关掉"自动链会用它们"）。

  同时把"基本面零测试"的这块先补钉（`engineList`/`requestedEngines`/`layerList` 三函数纯函数、最好下钉）。
